# 🏆 Geometry Dash Demonlist Website

Веб-приложение-демонлист, разработанное по заказу YouTube-блогера с аудиторией 90 000+ подписчиков. Сайт рассчитан на резкие скачки трафика после выхода новых видео.

## 🛠️ Стек технологий

![Next.js](https://img.shields.io/badge/Next.js-000000?style=for-the-badge&logo=next.js&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-06B6D4?style=for-the-badge&logo=tailwind-css&logoColor=white)

- **Фреймворк:** Next.js
- **Язык:** TypeScript
- **Стили:** Tailwind CSS
- **Тип проекта:** Коммерческая разработка для внешнего заказчика

## ✨ Что сделано

- **Разработка с нуля по ТЗ заказчика.** Спроектировал и реализовал архитектуру приложения, соответствующую требованиям блогера.
- **Работа с заказчиком.** Вёл прямую коммуникацию: уточнял требования, согласовывал макеты, оперативно вносил правки.
- **Адаптивная вёрстка.** Сайт корректно отображается на мобильных устройствах — а это основной трафик с YouTube.
- **Оптимизация производительности.** Быстрая загрузка страниц для комфортного просмотра большой аудиторией.
- **Сдача проекта в срок.** Все этапы согласованы и выполнены в оговорённое время.
- **Проявлял инициативность.** Помог разобраться в работе VPS и мы вместе выбрали хостинг для размещения на нём сайта. Рассказал про админ-панель и объяснил, зачем она нужна.
